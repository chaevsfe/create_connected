# Create Fly: Connected (Unofficial Port)

Quality-of-life additions for Create: gearboxes, clutches, item silos, fluid vessels, kinetic batteries, copycat blocks and fan catalysts.

> [!IMPORTANT]
> **This is an unofficial port.** It is not affiliated with or endorsed by
> hlysine. 
> Please report problems here.

## Compatibility

| Component | Version |
| --- | --- |
| Minecraft | `26.2` |
| Mod loader | Fabric Loader `0.19.3` or newer |
| Create Fly | `6.0.9-1` or newer |
| Fabric API | required |
| Java | `25` or newer |
| Environments | Client and server |

## Download

- [Modrinth](https://modrinth.com/project/Ph8gFiiY)
- [CurseForge](https://www.curseforge.com/minecraft/mc-mods/create-fly-connected)
- [GitHub releases](https://github.com/chaevsfe/create_connected/releases)


## Building

```
git clone https://github.com/chaevsfe/create_connected
cd create_connected
./gradlew build
```

Requires JDK 25.
