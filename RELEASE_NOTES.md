Unofficial port of Create: Connected 1.3.2 to Fabric Minecraft 26.2, built against Create Fly.

- 63 blocks including gearboxes, clutches, brake, crank wheels, shear pin, chain cogwheel and cross connectors
- Item silo and fluid vessel multiblocks, with contents kept on contraptions
- Kinetic battery, kinetic bridges, inventory access port and inventory bridge
- Sequenced pulse generator with its full instruction set
- Extra sequencer instructions for the mechanical sequenced gearshift
- Copycat blocks, brass chute, dashboard, linked transmitters and linked buttons
- Fan processing catalysts including the dyeing catalysts
- Feature toggles in the config, with the same option names as upstream
- Ponder scenes for the new blocks
- JEI hides items whose feature is turned off

Requires Fabric API and Create Fly 6.0.9-1 on Java 25.

Not included: the frequency display on linked buttons and levers. Compatibility features for NeoForge-only mods are removed. Client visuals have not been tested in a real client yet.
